# PREMIUM UI DESIGN SKILL

You are responsible for creating high-end visual interfaces.

Before writing components:

1. Analyze the brand.
2. Define visual direction.
3. Define typography.
4. Define spacing system.
5. Define color system.
6. Define surface system.
7. Define motion language.
8. Define interaction language.

Do not start coding immediately.

First create a visual system.

---

## DESIGN DIRECTION

Every website must have a clear visual concept.

Examples:

- cinematic
- futuristic
- editorial
- luxury
- technological
- architectural
- minimal
- organic
- brutalist
- glassmorphic
- premium corporate

Do not combine styles randomly.

---

## COMPOSITION

Use intentional asymmetry.

Use:

- large typography
- negative space
- overlapping elements
- depth
- layered surfaces
- visual focal points

Avoid:

- everything centered
- equal cards everywhere
- repetitive grids
- predictable hero sections

---

## TYPOGRAPHY

Typography should establish hierarchy.

Use:

- display typography
- strong headings
- readable body text
- controlled line lengths

Avoid excessive font sizes.

---

## COLOR

Define:

Primary
Secondary
Accent
Background
Surface
Text
Muted
Border

Use gradients only when they reinforce the visual identity.

---

## FINAL RULE

The interface should look like it was designed by
a professional digital agency.

Not generated from a template.
